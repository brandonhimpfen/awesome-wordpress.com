> A curated list of resources for WordPress.com hosted platform, Jetpack services, WordPress.com REST API, Studio local development, Model Context Protocol (MCP) AI integration, VideoPress, and managed hosting tooling.

WordPress.com is a managed cloud platform and hosted service developed by Automattic. Combining high-availability edge infrastructure, built-in security, global CDN caching, and automated scaling, WordPress.com extends standard WordPress with proprietary Jetpack cloud services, high-frequency CPU isolation, Model Context Protocol (MCP) AI integrations, custom domain management, and specialized API suites. This list is intended for cloud developers, WordPress.com site owners, digital creators, headless application engineers, and enterprise platform administrators.

## Platform Core & Developer Tooling

Local development environments, deployment utilities, and platform tools engineered specifically for WordPress.com workflows.

- [Studio by WordPress.com](https://developer.wordpress.com/studio/) — Fast, free local development environment developed by Automattic for building and testing WordPress sites locally before syncing to WordPress.com.
- [WordPress.com Command Line (WP-CLI Ext)](https://github.com/wp-cli/wp-cli) — Command-line interface extension modules designed for interacting directly with hosted WordPress.com site environments and SSH channels.
- [GitHub Deployments for WordPress.com](https://developer.wordpress.com/docs/developer-tools/) — Automated deployment pipelines syncing code from GitHub repositories directly to hosted WordPress.com production and staging sites.

## APIs & Headless Integrations

API endpoints, authentication protocols, and SDKs for consuming WordPress.com content outside the traditional admin interface.

- [WordPress.com REST API](https://developer.wordpress.com/docs/api/) — Platform REST API providing OAuth2-authenticated endpoints for managing sites, posts, media, comments, and stats across hosted accounts.
- [WordPress.com Node.js SDK](https://github.com/Automattic/wpcom.js) — Official JavaScript/TypeScript client library for wrapping the WordPress.com REST API in Node.js and browser applications.
- [WordPress.com OAuth2 Endpoint](https://developer.wordpress.org/rest-api/) — Secure OAuth2 authentication service enabling third-party apps to access hosted user data safely.

## Jetpack Cloud Services & Media

Built-in cloud performance plugins, high-definition video hosting, and search engines integrated into the hosted platform.

- [VideoPress](https://wordpress.com/features/) — High-performance, ad-free 4K video hosting and adaptive streaming player built into WordPress.com plans.
- [Jetpack Search](https://jetpack.com/search/) — Ultra-fast, cloud-indexed search engine powered by Elasticsearch for high-volume WordPress.com sites.
- [Akismet Anti-Spam](https://akismet.com/) — Automated cloud-based spam filtration service protecting comments and form submissions transparently.
- [Jetpack Social](https://jetpack.com/social/) — Automated social media distribution network for scheduling and broadcasting posts across external social channels.

## Managed Hosting & Edge Infrastructure

High-frequency CPUs, global content delivery networks, automated burst scaling, and sandbox staging environments.

### Global Edge & Performance

- [WordPress.com Global CDN](https://wordpress.com/features/) — Multi-continent edge network delivering cached static assets, dynamic images, and web content with low latency.
- [Automated Burst Scaling](https://wordpress.com/features/) — Dynamic resource management layer automatically scaling up to 100+ PHP workers to handle high-traffic spikes without site downtime.
- [Superior Image Management](https://wordpress.com/features/) — Cloud image processing service serving WebP conversions and responsive thumbnails on the fly.

### Staging & CI/CD Pipelines

- [WordPress.com Staging Sites](https://wordpress.com/features/) — One-click sandbox environments for safely testing plugin updates, theme modifications, and code deployments.

## AI & Protocol Integrations

Machine learning assistants, Model Context Protocol (MCP) extensions, and AI-driven site generation features.

- [WordPress.com MCP Integration](https://wordpress.com/features/) — Native Model Context Protocol (MCP) server integration allowing AI coding assistants like Claude, Cursor, and Copilot to interact directly with site backends.
- [WordPress.com AI Assistant](https://wordpress.com/features/) — Built-in block editor AI tool for generating structured content, translating text, and modifying page layouts.
